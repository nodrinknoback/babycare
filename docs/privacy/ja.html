本ポリシーは BabyCare Android アプリ（com.zero.babycare）に適用されます。開発者：copydog。プライバシーに関する連絡先：nodrinknoback@gmail.com。

1. 端末内で扱うデータと目的
BabyCare は保護者による赤ちゃんの日々の記録を支援します。入力した名前、性別、誕生日、授乳・食事、睡眠、おむつ、体温、服薬、予防接種、成長、活動、メモは端末内のアプリ専用領域に保存されます。記録管理、端末内での集計、成長曲線、授乳・睡眠の予測、リマインダーに使用します。設定やタイマーの状態も端末内に保存されます。管理する権限がある情報のみ入力してください。

2. 収集・共有と第三者
現在のバージョンではアカウント登録は不要です。育児記録を開発者のサーバーに送信せず、販売や広告事業者への共有も行いません。広告、行動分析、遠隔クラッシュ報告サービスは組み込まれていません。集計と予測は端末上で実行します。Room、MMKV などの基盤部品は端末内の処理に使用します。現在のアプリはインターネットへのアクセス権限を要求しません。

3. 権限・通知・バックアップ
通知権限は、有効にした端末内の育児リマインダーにのみ使用します。アプリやシステム設定で停止できます。通知文がロック画面に表示される場合があるため、必要に応じて通知のプライバシー設定を変更してください。インポートとエクスポートにはシステムのファイル選択画面を使用し、選択したファイルだけにアクセスします。バックアップには出力した赤ちゃんの情報と育児記録が含まれ、ファイル自体は暗号化されません。信頼できる場所に保存してください。クラウド保存先を選ぶ場合、その事業者が独自のポリシーに従ってファイルを扱います。アプリの Android 自動バックアップは無効です。

4. 保存期間・安全性・削除
データは、記録や赤ちゃんの情報の削除、アプリデータの消去、アンインストールまで端末内に残ります。赤ちゃんの情報を削除すると関連記録も削除されます。出力済みファイルは別途保存先から削除する必要があります。アプリは Android のアプリ隔離と端末の保護機能を利用し、独自のデータベース・バックアップ暗号化は提供しません。開発者はローカルデータのコピーを持たず、復元や遠隔削除はできません。端末とバックアップを適切に管理してください。

5. 子どもの情報と健康に関する注意
本アプリは成人の養育者向けで、子どもが単独で使うことを想定していません。赤ちゃんの情報は保護者が管理します。BabyCare は医療機器ではなく、病気の診断、治療、治癒、予防を目的としません。成長の参考値、予測、通知は記録整理を支援するもので、専門的な医療助言の代わりにはなりません。医療上の助言、診断、治療については医療専門家に相談してください。

6. お問い合わせと改定
プライバシーに関する質問や、自発的に送ったサポートメールの削除依頼は nodrinknoback@gmail.com へご連絡ください。メールと提供情報は対応のためだけに使用し、対応後に保持する必要がなくなった時点で削除します。メール事業者は独自のポリシーに従って処理します。不要な赤ちゃんの健康情報は送らないでください。公開ページは GitHub Pages で提供され、閲覧時に GitHub が IP アドレスやアクセスログを処理する場合があります。GitHub のプライバシー声明（GitHub Privacy Statement）をご確認ください。改定時はアプリと公開ページに更新日を表示します。
